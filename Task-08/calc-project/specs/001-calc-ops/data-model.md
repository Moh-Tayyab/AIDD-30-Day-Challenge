# Data Model for Basic Calculator Operations

The calculator library operates primarily on numeric data types: integers (`int`) and floating-point numbers (`float`). There are no complex entities, relationships, or persistent storage requirements for this library.

## Entities

-   **Number**: Represents an input or output value for an operation.
    -   **Attributes**:
        -   `value`: The numeric value (can be `int` or `float`).
    -   **Validation**: Numeric type (int or float).
